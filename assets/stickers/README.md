# Yuristim Sticker Pack

Brand colors: #00865F, #005C40, #DDF5E9.

- `yuristim-logo`: Original brand logo
- `create-account`: Registration
- `profile-setup`: Profile editing
- `special-login`: Six-digit PIN login
- `secure-login`: Password login
- `telegram-verification`: Telegram identity verification
- `confirmation-pending`: Pending confirmation
- `verification-success`: Successful verification
- `telegram-connected`: Active Telegram connection
- `telegram-disconnected`: Inactive Telegram connection
- `authentication-error`: Authentication error
- `empty-chat`: Empty chat history

PNG and lossless WebP, RGBA, 1024/512/256 px, centered with approximately 12% minimum padding. Original logo JPEG retained; transparent logo derived from it. Six missing illustrations were drawn as flat vector artwork; other five use generated artwork.
